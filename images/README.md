# 이미지 교체 가이드 (직접 사진 넣기)

아래 폴더에 **같은 파일명으로 덮어쓰기**만 하면 사이트 사진이 바뀝니다.
(코드 수정 필요 없음. GitHub에서 폴더 열기 → Add file → Upload files → 같은 이름으로 올리기)

## 정적 이미지 (레포 폴더에서 관리)

| 위치 | 파일 | 권장 비율 | 설명 |
|---|---|---|---|
| 소개 프로필 | `images/profile/portrait.jpg` | 세로 3:4 | 이희배 프로필 사진 |
| 이야기 썸네일 1 | `images/journal/01.jpg` | 세로 4:5 | 첫 번째 이야기 카드 |
| 이야기 썸네일 2 | `images/journal/02.jpg` | 세로 4:5 | 두 번째 이야기 카드 |
| 이야기 썸네일 3 | `images/journal/03.jpg` | 세로 4:5 | 세 번째 이야기 카드 |
| 공유 썸네일(OG) | `images/web/og-thumbnail.jpg` | 가로 1200x630 | 링크 공유 시 미리보기 |

- 파일 형식: jpg / png / webp 다 가능. 이름만 위와 똑같이 맞추면 됩니다.
- 새 이야기 카드를 늘리고 싶으면 `04.jpg`, `05.jpg` … 넣고 저(작업자)에게 말해주세요.

## 프로젝트 작업 사진 (Work) — 여기는 폴더 아님

Work 섹션의 프로젝트 이미지는 레포 폴더가 아니라 **관리자 페이지**에서 관리됩니다:
`pearway.kr/admin` 접속 → 프로젝트 Edit → Upload Image → Export JSON → GitHub push.
(폴더 방식으로 바꾸고 싶으면 말씀 주세요 — 구조 변경 가능)
